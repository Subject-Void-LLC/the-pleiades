`pleiades add-credential --password-file` stores a password from a sealed file, so it never has to be typed, piped or redirected. `pleiades seal-key` prints the project's public seal key (making it on first use), and `pleiades seal` seals a password to that key, or to a passphrase, on any machine. A sealed file keeps the password out of command lines, shell history and transcripts; it does not hide it from anyone who can read the project's `.pleiades/` directory, since the master key there opens it.
