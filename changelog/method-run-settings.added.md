Added run settings: a value a whole run gives a method's parameter for every task that leaves it out, named `<method>.<parameter>`, with the task's own value still winning. Give one with `--setting` on `pleiades run`, `adhoc` and `rollback` (`--setting file.remove.check_forbidden=warn`), or on the Controller with the `method_settings` launch field on a template, a saved configuration or a launch, and on a rollback when the job's template opens that field. A setting no method declares, or a value outside its choices, is refused before any device is contacted. The first one is `file.remove`'s `check_forbidden`, so a rollback check of a recorded removal can ask to be warned rather than refused.
