Added `controller version`. The controller now opens its port before it migrates the database, answering as alive and not ready, so a long migration is no longer killed by a startup probe. On shutdown it reports itself not ready and keeps serving for `SHUTDOWN_DRAIN` (default 5s; the chart's `controller.shutdownDrainSeconds`, default 20) before it closes its port, so a rolling upgrade drops no requests. Each controller records a heartbeat in the database, which `migrate --plan` lists.
