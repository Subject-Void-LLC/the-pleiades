Added the `vbox` inventory sync plugin: `pleiades inventory sync --plugin vbox --endpoint https://<host>:5986 --credential <host device>` reads a VirtualBox host's VMs over WinRM and brings each clone in as the device that reaches its guest (a Windows VM as `windows_server`, a Linux one as `linux_server`, at the address `virt.vbox.vm.clone` recorded), quarantining a VM with no recorded address or an OS type no rule places.
