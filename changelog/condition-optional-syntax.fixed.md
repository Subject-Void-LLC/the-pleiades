A condition written with CEL's optional field or index (`device.?name`, `result[?"probe"]`, `vars.?region.orValue("x")`) is now read like any other: one that reads `device`, or variables that differ by device, is decided on each device instead of failing with "no such attribute(s): device" or being decided once, `--tags` no longer refuses a runbook holding one, and a check tells a field a prediction lacks from a misspelled register in one. An optional read whose optional is used safely (`hasValue()`, `orValue(...)`, `or(...)`, `optMap`, `optFlatMap`) counts as written for a missing name, as `has()` does; one whose value is taken (`.value()`) is a plain read.
