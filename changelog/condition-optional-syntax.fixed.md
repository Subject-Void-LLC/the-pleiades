A condition written with CEL's optional field or index (`device.?name`, `result[?"probe"]`, `vars.?region.orValue("x")`) is now read like any other: one that reads `device` or a device's variables is decided on each device rather than failing with "no such attribute(s): device", `validate` holds its register, variable and `error` reads to the runbook and counts an optional read as written for absence, `--tags` and a check see what it reads, and a condition whose reads cannot be told is refused rather than taken to read nothing.
