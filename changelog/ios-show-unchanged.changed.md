`net.ios.command` now reports a `show` command (or IOS's abbreviation of it) as unchanged, unless its output is sent to a file with `| redirect`, `| append` or `| tee`, so a second run of a runbook that only reads proves it changes nothing. Any other command still reports changed. The skill and `docs/16-network-verification.md` now say that an IOS change records no undo, and how to give its task a `rollback:` list.
