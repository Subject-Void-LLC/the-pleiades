`add-credential` now warns when the device name is not in the inventory it read (the `--inventory` file when one is given), naming the closest device names, and marks such a credential unbound; `--no-device` says no device is meant and silences the warning, `pleiades list-credentials` lists every credential (never a value) with its unbound mark, and the first run that uses an unbound credential says so. From 0.4.0 such a name will be refused without `--no-device`.
