WinRM gets the same circuit breaker as SSH: after five network failures in a row against one address, calls to it fail at once for thirty seconds without sending anything, then one call is let through to see whether the device is back. Only a failure of the network counts. A refused credential, a client certificate the host turns down, or a failure after the command started does not. A client certificate the host refuses with a TLS alert is also no longer retried.
