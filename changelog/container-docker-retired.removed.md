`container.docker.run`, `stop`, `remove` and `exec` no longer exist; rename them to `container.run`, `container.stop`, `container.remove` and `container.exec`, which reach Docker or Podman through the engine's own API. `container.run` pins its image by digest and defaults to no network and read-only mounts, so set `network:` where a container needs one, and `pull: never` for an image loaded onto the engine rather than pulled.
