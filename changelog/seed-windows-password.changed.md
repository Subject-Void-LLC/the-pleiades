A method that seeds a machine with a device's login (`virt.vbox.vm.clone`) now receives that device's password itself when the device is reached over WinRM, and only then, since a Windows answer file can hold nothing else; the method must declare it can (`SeedsLoginPassword`). A device reached over SSH still gives only its public key and a password hash. `pleiades add-credential --generate` now always makes a password with an upper case letter, a lower case letter and a digit, which Windows' default password policy requires; about one generated password in 38 used to lack a digit.
