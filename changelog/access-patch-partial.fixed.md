`PATCH /organizations/{id}`, `PATCH /teams/{id}`, `PATCH /contacts/{id}` and `PATCH /bindings/{id}` are now partial updates: a field the body leaves out keeps its stored value, where it used to be blanked, so a PATCH that sent only an organization's new name unfroze it and erased its description, classification, change window, freeze reason, cost centre, ticket key and CMDB id, one that sent only a team's name erased its description, one that sent only a contact's notes was refused for the name and channels it blanked, and one that sent only a grant's role was refused for the effect it blanked. An empty value clears a field that can be empty, `"frozen": false` lifts a freeze, and the record as it would be saved is still checked whole, so a contact PATCH that clears its only channel is refused; concurrent PATCHes are still last-writer-wins, with no version check.
