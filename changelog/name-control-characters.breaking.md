A device can no longer be created under a name holding a byte that is not UTF-8, a control character (a newline, a carriage return, an escape, DEL or a C1 control), a text direction control, a line or paragraph separator, a soft hyphen, a zero width space, a word joiner, a byte order mark or a tag character, since the name is printed wherever the device is named and such a name would not show as itself. `POST /inventory/devices`, the kubeconfig import, the web UI's device form, `pleiades add-host`, `pleiades import-kubeconfig` and every import refuse such a name, naming the character by its code point and never repeating the name, and `pleiades inventory sync` reports such an upstream device as refused and adds the rest; spaces, accented letters, other scripts and the zero width joiner and non-joiner are still allowed, and devices already stored are not changed.
