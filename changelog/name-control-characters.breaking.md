A device can no longer be created under a name that would not show as itself, since the name is printed wherever the device is named: a name holding a byte that is not UTF-8, a control character (a newline, a carriage return, an escape, DEL or a C1 control), a format character (a text direction control, a soft hyphen, a zero width space, the zero width joiner and non-joiner, a word joiner, an invisible math operator, a byte order mark, a tag character), another character Unicode marks default-ignorable (such as a Hangul filler), a variation selector, a space other than U+0020 (a no-break space among them), a line or paragraph separator, the blank braille pattern, a private-use character or a noncharacter, or spaces alone. A new fact key is held to the same rule. `POST /inventory/devices`, the kubeconfig import, the web UI's device form, `pleiades add-host`, `pleiades import-kubeconfig` and every import refuse such a name, naming the character by its code point and never repeating the name, and `pleiades inventory sync` reports such an upstream device as refused and adds the rest. A name written with a joiner or a variation selector (a Persian word spelled with the non-joiner, an emoji in its color form) must now be written without it. U+0020, accented letters and other scripts are still allowed, and a device already stored under such a name is not changed and is still updated by a sync and replaced by a kubeconfig import with replace.
