`PATCH /projects/{id}` is now a partial update: a field the body leaves out keeps its stored value, where it used to be blanked, so a PATCH that did not name `credential` unbound the project's credential, one that did not name `scm_type` turned a manual or archive project into git, and one naming a single field was refused for the name and URL it blanked. `"credential": 0` unbinds, an empty value clears `description`, `scm_url` and `scm_branch`, an `scm_url` equal to what `GET` shows for a URL carrying a credential (redacted, or withheld whole) keeps the stored URL rather than saving what was shown, and the project as it would be saved is still checked whole, so setting `scm_type` to git on a project with no URL is refused; concurrent PATCHes are still last-writer-wins, with no version check.
