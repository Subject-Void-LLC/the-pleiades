Added `net.ios.parse`, which runs a show command on a Cisco IOS or IOS XE device and returns its output in the structure Cisco's Genie returns for it, through parsers ported to Go from genieparser (Apache License 2.0, kept with its notice in `pkg/iosparse`) and held to every one of genieparser's recorded outputs for the command forms covered: `show version`, `show inventory`, `show ip interface brief`, `show interfaces`, `show ip route`, `show ip ospf neighbor`, `show ip bgp summary` and `show bgp ... summary`, `show vlan`, `show cdp neighbors`, `show lldp neighbors` and `show archive config differences`, whose secrets are masked. Output the parser finds nothing in is an empty result, so a state before a change and after its rollback can be compared.
