Added SFTP and legacy SCP file transfer libraries for Collection authors (`pkg/sftpxfer` and `pkg/scpxfer`, behind one `pkg/filexfer` port), which stream files of any size over the existing SSH connection and replace a file atomically. A `linux_server` becomes `FileTransferCapable` when its `file_transfer_root` property is set, and every transfer is confined to that directory, symlinks included; no runbook task uses them yet.
