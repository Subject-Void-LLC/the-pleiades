Signing in with a password now refuses an address holding bytes that are not UTF-8, a control character, a tab or line break, or a text direction mark, rather than repairing it into what could be another stored address or failing faster than an unknown address does; creating a user refuses the same addresses. A password over the 1,024-byte limit is refused before the address is looked up, so it no longer reveals whether an account exists or counts toward that account's lockout.
