Pleiades makes Windows Server VMs on a VirtualBox host, two ways, each ending in a generalized base to snapshot and clone. `virt.vbox.vm.import_disk` makes a VM from a disk image already on the host, such as Microsoft's Windows Server evaluation VHDX: the image is copied into the VM's folder and left unchanged, and the VM boots EFI or BIOS as the disk's partition table says. `virt.vbox.vm.install` installs Windows from its ISO with no one at the keyboard, through an answer file Pleiades builds, then generalizes it and waits for it to shut down, pointing Windows at the DVD a clone's seed will be on, since a generalized Windows never looks on a DVD by itself; running it again resumes an install that stopped waiting. `virt.vbox.vm.clone` seeds a clone of a Windows VM with its own answer file (computer name, fixed address, the Administrator's password), and the new `virt.vbox.vm.eject_seed` takes a clone's seed out once the first boot has read it and deletes it, which VirtualBox allows only once the VM is stopped, for Linux and Windows alike. Microsoft's evaluation VHDX makes a VM but its clones do not read their seed.
