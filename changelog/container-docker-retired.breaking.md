`container.docker.run`, `container.docker.stop`, `container.docker.remove` and `container.docker.exec` are gone. They are replaced by the `container.*` methods, which reach Docker or Podman through the engine's own API rather than the docker command line: `container.run`, `create`, `start`, `stop`, `restart`, `remove`, `recreate`, `exec`, `info`, `list`, `logs`, `prune`, `copy_in` and `copy_out`. To update a runbook, rename each task's method: `container.docker.run` becomes `container.run`, and likewise for `stop`, `remove` and `exec`. `container.run` pins the image by digest, and by default runs with no network and with read-only mounts. If a container needs a network, set `network:` explicitly. If an image was loaded onto the engine rather than pulled, so it has no registry digest, set `pull: never`.
