After a real install or upgrade, `pkg.apt.install`, `pkg.apt.upgrade`, `pkg.dnf.install` and `pkg.dnf.upgrade` read the package back and record its `package.<name>` fact exactly as `facts.gather` would, so the change has its observed result beside it and the next gather does not read it as drift. A check, an unchanged run and a removal record nothing, and a failed read-back is a warning, not a failure.
