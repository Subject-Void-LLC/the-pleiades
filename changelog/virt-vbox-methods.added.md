Six `virt.vbox.*` methods manage VMs on a host that runs VirtualBox, targeting the host (a device with `virtualbox: true`) and naming the VM as a parameter. `virt.vbox.vm.info` reads a VM; `virt.vbox.vm.start` and `virt.vbox.vm.stop` start it headless and stop it by its power button or its power, each recording the other as its inverse; `virt.vbox.snapshot.take`, `restore` and `delete` manage its snapshots, a take recording the delete of exactly the snapshot it made. On a Windows host, a start with none of the account's VMs running goes through the account's VirtualBox autostart service, since Windows refuses to start a VM from a WinRM logon. All six support check mode, and VM and snapshot names outside a strict character set are refused rather than quoted.
