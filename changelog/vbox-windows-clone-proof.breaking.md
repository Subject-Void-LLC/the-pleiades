`virt.vbox.vm.clone` now proves a Windows clone took its answer file: it starts the clone, waits up to `timeout` (default 1200 seconds) for the seeded Administrator to log in over WinRM at the fixed address with the computer name asked for, then shuts it down and deletes the answer file. A clone not proven is powered off and deleted and the task fails, where it used to succeed with a VM booted on its base's own account; `timeout` is refused for a Linux or FreeBSD clone.
