`pleiades forge new-external` now writes a minimal `go.mod` (a module line and a go line, nothing to resolve by hand), so a new program builds with `go mod tidy` and `go build`, and one scaffolded inside another checkout stays out of that checkout's builds. The README gives the offline route through a local checkout as an explicit step, and `--no-go-mod` leaves the file out for a program meant to join a module of your own.
