Fixed a rollback that could undo a run beneath a later run that changed the same device when a clock was set back between the two runs, or when two Runners' clocks disagreed. "Later" is now decided by a run counter the CLI keeps in `.pleiades/clock` (a run killed before it ended is bounded by the next run to begin) and by the revision of the device lease a Runner held, within one life of the lock store, not by the journals' times. Journals written before this, jobs on a device that takes a shared lease, and what a job records after its Runner lost its lease are still ordered by time, which a refusal says, and which `pleiades rollback` also names (`ordered_by_clock`).
