Fixed a rollback that could undo a run beneath a later run that changed the same device when a clock was set back between the two runs, or when two Runners' clocks disagreed. "Later" is now decided by a run counter the CLI keeps in `.pleiades/clock` and by the revision of the device lease a Runner held, not by the journals' times; journals written before this, and jobs on a device that takes a shared lease, are still ordered by time, which a refusal says, and which `pleiades rollback` also names (`ordered_by_clock`).
