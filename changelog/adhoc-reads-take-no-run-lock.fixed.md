An `adhoc` call that only reads (a method that declares it read-only for the parameters written, such as a literal `net.ios.command` show) no longer takes the project's run lock, so pollers of reads keep running during `pleiades rollback` and no rollback is refused for them, where before each such call made a rollback refuse "another run or rollback holds this project's run lock"; a rollback plans past a read still running beside it. A tick of the run counter that waits over ten seconds for its lock now names the process holding it, its command and for how long.
