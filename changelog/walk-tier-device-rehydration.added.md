A Runner rebuilds each dispatched device as its real type, so a method that reads a device's settings works on the Walk tier as it does from `pleiades run`: `http.request` calling a `generic_http` device's own API, `net.netconf.config` reading a NETCONF port, and the generic `pkg.*` and `svc.*` methods reading which package or service manager a device runs. The dispatch now carries the device's type and only the properties its type declares its accessors read, plus its discovery, and never any other property. A generic device whose address is part of its URL or target is dispatched to that address instead of being skipped for having no `host`. A Runner given a dispatch from an older Controller reaches the device by address alone, as before.
