Low severity: a name holding an escaped `/` used to reach a device's API as two path segments, so a `virt.clab` call or an `http.request` device path could land on another route of the same server with the device's credential, and a CML lab ref of `..` was sent as a literal `..` with the controller's token. Now an `http.request` device path holding `%2F` or any other escape is sent exactly as written, a lab, network or project id of `.` or `..` is refused before anything is sent, a Catalyst Center base URL with a dot segment is refused, and Batfish, GNS3 and Google model names are no longer escaped twice.
