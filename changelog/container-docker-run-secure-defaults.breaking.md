`container.docker.run` is secure unless the task says otherwise. A container joins no network (`network: none`); `network` names `bridge`, `host` or a network on the host, and `ports` are refused without one. Each volume is mounted read-only unless its options say `rw` (`/srv/data:/data:rw`). The image is resolved to its ID, pulled first when the engine holds none of it, and the container starts from that ID, so a tag that moves cannot change what runs; the ID is returned as `image_id`. A runbook that published ports or wrote to a volume must now say `network:` and `:rw`.
