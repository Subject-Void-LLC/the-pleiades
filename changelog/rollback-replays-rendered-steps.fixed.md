A later `pleiades rollback` or Controller rollback runs a task's templated `rollback:` steps with the values the run rendered for them on each device, which the journal now keeps (journal format 3), instead of rendering the step again without the run's variables. A step whose values the journal may not keep (a secret, a parameter the task's method does not declare recordable for that undo), one the journal holds no copy of, and one edited since the run are refused by name before any device is touched.
