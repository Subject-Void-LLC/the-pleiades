`facts.gather` now records four identity facts on Linux, FreeBSD, macOS and Windows: `os.machine_id`, `hardware.system_uuid`, `hardware.serial` and `hardware.virtualization` (`physical`, `vm:<hypervisor>`, `cloud:<provider>` or `container:<engine>`). Firmware placeholders such as "To be filled by O.E.M." are never stored (the set measured on Linux, applied on every system). On Linux the UUID and serial, which only root may read, are simply absent for a login without root; FreeBSD and macOS give them to any login, and Windows was measured with an administrator's login. The machine id is `/etc/machine-id` on Linux and FreeBSD and the install's `MachineGuid` on Windows, in the same 32-digit shape; macOS has none and reports none. The UUID is lowercase on every system. Inside a container (WSL included), a FreeBSD jail or a Windows container the machine id, UUID and serial are not recorded at all: a container sees its host's values and its image's machine id, so every container of one image would otherwise read as one machine. A jail reads as `container:jail` and a Windows container as `container:windows`. A hypervisor has the same name on every system, systemd-detect-virt's (`oracle` is VirtualBox, `microsoft` is Hyper-V, `other` is one the system does not name), and a Windows guest is also known by its firmware's vendor, as systemd reads it. Azure and Hyper-V both read as `vm:microsoft`, since the system cannot tell them apart, and FreeBSD and macOS do not tell a cloud instance from a virtual machine. Only VirtualBox guests and a physical Mac were measured; a jail, a Windows container, a macOS guest and a Hyper-V or VMware guest were not. On firmware older than SMBIOS 2.6, VirtualBox's among them, Windows reads the UUID's first three parts byte-swapped from how Linux and FreeBSD read them, so one virtual machine can report two UUIDs. A baseline taken before this release with no `--keys` reads each new identity fact as added, so drift reports it once on every device that has one: take the baseline again after the first gather, or narrow it with `--keys`.
