VirtualBox VMs come in T-shirt sizes: `virt.vbox.vm.clone` takes `size` (xsmall, small, medium, large or xlarge, each a CPU count and a memory size together) in place of `memory_mb` and `cpus`, and the new `virt.vbox.vm.resize` changes a stopped VM's size or either number, recording the size it had as its undo. `virt.vbox.vm.info` and `virt.vbox.vm.list` report a VM's size, a clone that finds a VM of another size warns rather than reporting a silent success, a VM larger than the host is refused before it is made, and `virt.vbox.vm.start` refuses a VM the host's free memory cannot hold.
