SSH connections no longer agree to SHA-1 key exchange (`diffie-hellman-group14-sha1`), `ssh-rsa` (SHA-1) or DSA host key signatures, or `hmac-sha1-96`, which the SSH library still offered by default; an RSA host key is still accepted through `rsa-sha2-256` and `rsa-sha2-512`. An old device that offers nothing better (an IOSvL2 15.2 switch) is refused naming what it offered and the per-device flag that allows it, `ssh_allow_legacy_key_exchange`, `ssh_allow_legacy_host_keys` or `ssh_allow_legacy_ciphers`, each warned about on every run, onboarding and `trust-host --first-connect` that uses it, and a handshake that finds no algorithm in common is no longer retried or counted against the address's circuit.
