Named database connections: `pleiades add-database-connection`, `list-database-connections` and `remove-database-connection` store a PostgreSQL server's host, login, password (encrypted), TLS settings and live databases under a name a `db.pg` task refers to, so a runbook never carries any of them. On the Walk tier the managed `pleiades_postgres` credential type, of a new `database` kind, carries the same, and a template may bind several, one per name. A connection's password reaches only the method whose task names it, and is masked from every output.
