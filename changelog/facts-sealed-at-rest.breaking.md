Facts stored before this release are not kept, since a plaintext fact cannot be converted to a sealed one. The controller's upgrade deletes them, and each device's next gather stores its facts again. On the command line a device's files under `.pleiades/facts` written by an earlier release are refused with an error saying so: remove them and gather again. A controller with no `PLEIADES_FACTS_DIGEST_KEY`, and a project with no master key, now store and read no facts at all. A Runner of this release publishes no facts to a controller that sends it no key, so upgrade the controller and its Runners together. The controllers cannot be rolled one at a time across this upgrade: stop every older controller, then start the new one, which refuses to migrate while it still sees an older one running; afterwards an older build refuses the database.
