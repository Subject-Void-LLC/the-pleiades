The playbook converter now translates three more fact constructs instead of refusing them. A `setup` task's `filter` is expanded to the native fact names its patterns match, with Ansible's own matching rules (the `ansible_`, `facter` and `ohai` prefixes, a list as a union, and a pattern that keeps everything leaving no filter); a pattern that matches nothing, a run-time value and a hardware-only filter under a subset without hardware are refused. Because Ansible's Windows setup ignores `filter` and gathers every fact, a filtered `ansible.builtin.setup` becomes two gathers, the filtered one for devices that are not `WindowsShellCapable` and an unfiltered one for those that are; a Windows host reached as `generic_ssh` without that capability gets the filtered gather. `ansible_distribution_major_version | int` compared with a whole number by any of the six comparisons converts, deciding as Jinja does on every host (0 where the major version is not a number); the bare text comparison is still refused, and its refusal names `| int` and `os.version_major`. OpenBSD's release words (`release`, `current`, `stable`, `beta`) are refused as codenames, naming OpenBSD, and the migration guide lists OpenBSD as not gathered.
