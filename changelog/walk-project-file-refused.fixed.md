A Runner now refuses, before any task runs, a runbook naming a project file (`net.frr.config`'s `src`, a `net.batfish.check` device's `src`, `file.template`'s `src`, `pleiades.builtin.project.write`'s `path`), since a Runner holds no project; before, the earlier tasks ran and the method then failed. An expression in `net.frr.config`'s `src` may now read only `vars`, as a project path's may.
