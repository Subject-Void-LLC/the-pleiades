The Runner now validates a dispatched runbook against the device it is about to run on before any task runs, with the same checks `pleiades validate` makes. It used to start straight away, so a task calling an unregistered or declared-only method, passing an undeclared parameter, or asking for `check_mode` on a method that cannot check failed only when reached, after every earlier task had already changed the device. A refused dispatch ends its job log with a failed event naming each finding.
