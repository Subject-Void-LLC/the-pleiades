Pleiades makes FreeBSD VMs on a VirtualBox host. `virt.vbox.vm.install` with `installer: freebsd` installs FreeBSD from its DVD with no one at the keyboard: it watches the VM's screen for the installer, starts a script Pleiades builds, and waits for the VM to power off, and running it again resumes an install without typing into one already running. The base's clones read the same NoCloud seed an Ubuntu clone does (a login other than root gets `/bin/sh`, since FreeBSD has no bash) and print their SSH host keys on the serial console, where `virt.vbox.vm.host_keys` and `trust-host --from-console` read them. `examples/virtualbox_lab` has the runbooks.
