Pull requests are tested in CI again: every container-free package, three times over, on Ubuntu (and on macOS while it earns a required place), the container packages in four parallel shards with their images cached, and the coverage ratchet from the numbers those runs recorded; a strict run of the whole suite happens nightly. Locally, `make ci` now runs the test suite once instead of three and a half times, `make ci-fast` runs everything that needs no Docker in minutes, `make doctor` says what your machine can verify and how to fix each gap, and every test run lists the tests it skipped and why.
