Gathering facts that have not changed no longer rewrites anything stored: each gather adds one record of what it saw (`.pleiades/facts/<device>.seen.jsonl` on the command line, a new table on the Controller), and when a value was last confirmed is read from those records, so a large fleet's hourly gathers stop updating millions of rows. A stored fact can no longer be moved to another device by an update, and the command line and the Controller now report the same last confirmation for a value seen again after a late result.
