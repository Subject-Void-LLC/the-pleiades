Every binary now reports its build: `pleiades version` and the new `runner version` print the release a build was stamped with, or `0.0.0-dev+<commit>` for a development build, and the images stamp it from their existing `VERSION` and `VCS_REF` build arguments. A release build refuses an external Collection program whose method states it needs a newer release, on the Runner as well as the command line; a development build loads it with one warning per program, and `pleiades doc` marks the constraint as not checked. `forge new-external` now writes the generating release as a new program's constraint, and none from a development build, instead of a fixed `>=1.0.0`.
