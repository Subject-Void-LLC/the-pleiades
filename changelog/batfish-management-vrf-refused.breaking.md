`net.batfish.check` now refuses a Cisco IOS configuration that puts an interface in IOS XE's `Mgmt-intf` management VRF, until the task accepts it with `accept_unrecognized: [{feature: management_vrf, reason: ...}]`: Batfish deactivates every interface in that VRF, so a check that passed used to say nothing of the management network it never modelled. A node made by `virt.cml.node.create` has its management interface there, so a check of one needs that line.
