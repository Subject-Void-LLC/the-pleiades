Added `pleiades forge new-external --script <file> --interpreter <absolute path>`, which turns a script into an external Collection: the program embeds the script, so the approved digest covers it, and its method runs it beside The Pleiades under the loader's confinement with the task's params as JSON on stdin, reading back exactly one JSON object (`changed`, and optional `stats` and `facts`). The method acts on no device, is never handed a credential, supports no check mode and records no undo; the interpreter is outside the approved digest, and the confinement restricts files, not the network.
