A job template's machine credential now reaches only devices it can log in to (over SSH, WinRM, NETCONF, a network command line or a console). Before, it was also sent to devices reached only through an API, such as a `generic_http` device, a Catalyst Center or an AWS account, so a device of that kind in a template's inventory received the machine credential, and `http.request` sent it as basic or bearer authentication to whatever answered at the device's URL.
