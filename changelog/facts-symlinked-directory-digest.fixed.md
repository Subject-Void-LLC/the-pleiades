`facts.gather`'s files subset no longer keeps a plain digest of a file reached through a symbolically linked directory. The world-readable check read the directories of the path as written, so a link to a directory under one that keeps others out (`pub/l` to `private/open`, `private` being 0700) made a file only the login could reach look world-readable, and its SHA-256 was stored unkeyed: an offline guessing oracle for a small secret. A linked directory anywhere in the path now makes the file private, so its digest is keyed and its size is not kept.
