The published OpenAPI document now describes the JSON bodies `POST /projects` and `PATCH /projects/{id}` take, with each field's byte bound, where it described neither, so a client generated from it did not know what to send. Creating a project always required its body, and the route answers no differently for the document's change, which is named here as the compatibility check reports it: `request-body-added-required openapi.json#/paths/~1projects/post/requestBody`.
