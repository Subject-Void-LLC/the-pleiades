Every command a method runs over SSH is now held to 64 MiB on each of standard output and standard error, and a command that writes more fails the task rather than returning part of its output: before, only the docker methods were bounded, and a device that wrote without end grew the memory of the process running the task until it failed. `exec.command`, `exec.shell` and `wait.search` say so; output that large is better fetched as a file.
