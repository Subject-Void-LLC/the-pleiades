Every run journal record now names the Collection its method came from (`collection`: a built-in's first-party group, the version of The Pleiades that ran it and a digest of the group's method declarations, or an external program's file name and a digest of what it described) and, for an undo a built-in method declares, a digest of that declaration (`inverse_spec_digest`), so a later rollback can tell an undo recorded by a different build from one whose documentation alone changed. A Crawl-tier journal line is now format 2; a 0.3 build refuses one by its format version rather than reading it, and this build still reads format 1. The Controller's `journal_entries` table gains the matching columns.
