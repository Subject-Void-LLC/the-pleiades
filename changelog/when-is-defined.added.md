Added Ansible's `vars.<name> is defined`, `is not defined` and `is undefined` as a whole `when:` item (and in `when_or`, `until`, `changed_when`, `failed_when` and an assert's `that`), meaning `has(vars.<name>)` or `!has(vars.<name>)`. It is asked only of a run variable: on a registered result, an `item` or any other root it is refused when the runbook is built, since the answer would not be Ansible's.
