A name with a slash, a space or another reserved character now reaches a device's API as the one name it is: `virt.clab` methods, `http.request` on a device path, `net.batfish.check`'s Batfish calls, the GNS3, CML and Catalyst Center clients, and Google model names each used to send such a name split in two or escaped twice. The API's links and the web UI now name the record that was asked for, and the UI gives no link, rather than a link to another page, for a record named `.` or `..`.
