A HashiCorp Vault secret reference whose mount or path held a percent-encoded dot or slash (`%2E%2E`, `%2F`) reached Vault as a `..` or a separator, so it could address an API path outside the secret it named with the source's token; each element is now sent escaped, as the characters it holds, one path segment each. A path written pre-encoded (`my%20secret`) is now read literally rather than decoded, so write it as the characters it holds, and a path holding a `%` no longer sends the request to the server's root instead of the secret.
