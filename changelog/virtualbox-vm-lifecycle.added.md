The Pleiades can make and remove VirtualBox VMs, not only start and stop them. `win.file.download` has a Windows host fetch a file over HTTPS and keep it only if its SHA-256 matches. `virt.vbox.vm.import_ova` imports an appliance with no network adapter; Ubuntu's cloud image asks for a bridged one. `virt.vbox.vm.clone` makes a linked clone of a snapshot, with NAT, a host-only adapter at a fixed address, a serial console written to a file, and a cloud-init NoCloud seed. `virt.vbox.vm.delete` removes a stopped VM with its disks, detaching shared install media rather than deleting it. `virt.vbox.vm.host_keys` reads a new VM's SSH host keys from its console, and `virt.vbox.vm.list` reports every VM on the host with the address it was given. The seed is rendered by The Pleiades (`pkg/cloudinit`, `pkg/iso9660`) and reaches the host on the command's standard input, never on a command line. `examples/virtualbox_lab` walks through all of it.
