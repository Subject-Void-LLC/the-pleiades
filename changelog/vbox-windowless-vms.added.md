Four methods see into a VirtualBox VM that has no window. `virt.vbox.vm.screenshot` saves a picture of a running VM's screen as a PNG on the machine running Pleiades. `virt.vbox.vm.log` reads the end of the VM's VirtualBox log, optionally only lines matching a pattern. `virt.vbox.vm.send_keys` types into a VM's console in Packer's `<enter>`/`<tab>` notation. `virt.vbox.vm.addresses` reports the addresses a VM's host-only adapters were given, from VirtualBox's own DHCP leases and from `virt.vbox.vm.clone`, which is how to reach a VM whose fixed address was never applied.
