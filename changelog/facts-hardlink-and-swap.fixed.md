`facts.gather`'s files subset no longer keeps a plain digest of a file with more than one hard link, which may also sit in a directory that keeps others out (the same file, with the same mode, reached by a path the world-readable walk finds public), and it reads the digest from the very file it judged: the file is opened once, the descriptor must be the device and inode the check examined, and a path swapped between the check and the read hands its digest over keyed rather than plain.
