Added `pleiades run --mode check`, a dry run: every task whose method declares check support reports whether it would change anything and changes nothing, every task that cannot be checked is named, and the command ends non-zero if any task went unchecked. A device in the simulate-locked state can now be checked, and is still never run against for real. A runbook can ask for a check itself with Ansible's `check_mode: true`, on the whole runbook, a block or a task; `check_mode: false` is refused, since it would run a task for real inside a check. An incomplete check ends with exit status 3 (a failure is still 1), and `--allow-unchecked <method>` accepts named gaps while still listing them. Every result a check produces, and its diff, carries `predicted: true`, set by the engine; a real run whose result claims it is refused.
