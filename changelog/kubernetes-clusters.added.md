Added Kubernetes clusters as devices. `pleiades import-kubeconfig` and the Controller's `POST /inventory/kubeconfig-imports` turn one kubeconfig context into a `kubernetes_cluster` and its stored credential, refusing anything that would run a program or read a file, and `pleiades onboard` records what the cluster serves at every version, what the credential may do, its nodes, and, for kind or Docker Desktop's cluster, which container each node is. A cluster behind a jump host takes a `route` like any SSH device, and `pleiades validate` refuses a manifest whose kind the cluster does not serve.
