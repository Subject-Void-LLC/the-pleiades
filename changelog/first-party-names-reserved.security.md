Every first-party namespace is now reserved for The Pleiades whether or not a build includes that Collection: an external Collection can no longer take `kubernetes`, the namespace of a built-in fact family (`os`, `host`, `package` and the rest), or a Collection's namespace in a build without it, and `pleiades validate` names the first-party Collection that holds a method a build does not include. The lists ship as `docs/reference/schemas/first-party.json` and grow only on a minor release.
