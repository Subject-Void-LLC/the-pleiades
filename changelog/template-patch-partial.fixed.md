`PATCH /templates/{id}` is now a partial update, as AWX's is: a field the body leaves out keeps its stored value, where it used to be blanked, so a PATCH that sent only a new name deleted the template's survey questions, emptied its defaults, prompts and required capabilities, and turned `allow_simultaneous` off. An empty value clears `description` (`""`), `defaults` (`{}`), `prompts` and `required_capabilities` (`[]`), a name may not be blank, and a survey is cleared with `{"enabled": false, "questions": []}`, since `survey.enabled` and `survey.questions` are each kept when left out; the template as it would be saved is still checked whole. Concurrent PATCHes are still last-writer-wins, with no version check.
