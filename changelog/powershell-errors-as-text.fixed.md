PowerShell errors from a Windows device read as text. `powershell.exe` writes its error output as serialized CLIXML whenever that output is not a console, so a failed PowerShell task over WinRM used to show `#< CLIXML <Objs ...>` with `_x000D__x000A_` in place of line breaks; it is now decoded, with warnings, verbose and debug messages prefixed as a console prefixes them and anything a native program wrote kept exactly as written.
