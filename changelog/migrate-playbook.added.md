Added `pleiades forge migrate-playbook <playbook.yml>`, which converts an Ansible playbook into native runbooks and prints a migration report of every construct that did not convert cleanly, once each, with its playbook line and column and the runbook line it landed on (`--json` prints the same report, described by `docs/reference/schemas/migration-report.json`). Modules are mapped by tables generated into `docs/reference/ansible-modules.md`; loops over a written list are unrolled, variables with one literal value are written in, and a bounded Jinja subset of `when:` becomes CEL. A construct is dropped only when that makes the task do less or fail sooner; anything else is blocked, and a runbook holding a blocked task is written as `<name>.incomplete.yaml` with a guard task first, which `pleiades validate`, `pleiades run` and the Runner all refuse. Secret-shaped and vault values are never copied or printed. The command exits 3 when anything needs a person. The Ansible-playbook rejection in `pleiades run` and `validate` now names the command.
