`facts.gather`'s Linux ports subset no longer lets a local user forge which process owns a listening socket. It read each process's descriptors from `ls -l`, which prints what a descriptor points to, so a file opened at a path whose directory names held a newline and a line shaped like a listing made another process (pid 1) the owner of a socket it did not hold. Each descriptor is now read with `stat -L`, which prints its type and inode beside its own `/proc/<pid>/fd/<n>` path, and a line of any other shape is ignored.
