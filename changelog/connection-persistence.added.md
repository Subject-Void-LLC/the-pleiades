Runs now keep one SSH connection per device open between that device's tasks, closed when the run ends or after 60 seconds idle, so ten tasks against a device log in once. Turn it off with `pleiades run --persist-connections=false`, the `persist_connections: off` launch field on a job template or launch, or a `persist_connections: false` property on an inventory, group or device; the most specific setting wins within each, and off at either the run or the device wins. A connection is never reused across a different credential, address or host key setting, after any edit to `known_hosts`, when it fails a keepalive, or after a task opened a terminal or NETCONF session or had a command cut off.
