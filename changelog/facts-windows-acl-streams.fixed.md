`facts.gather`'s Windows files subset now judges a file world-readable from the security descriptor of the very handle it hashes: any deny of read to anyone, a conditional entry, a mandatory integrity label or a central access policy makes it private, as does a junction, symbolic link or mounted volume on a directory above it, and a descriptor that cannot be read counts as private. A path naming an NTFS stream or another name for a file (`f.txt:x`, `f.txt::$DATA`, a trailing dot or space, `.` or `..`, an 8.3 short name) is refused. Each path's named streams are listed in `file_attached.<path>` with one keyed digest, bounded at 4096 streams, 64 MB a stream and 256 MB in all, a stream past a bound counted as `unread`. The script, past cmd.exe's 8191-character command line once it carries its Win32 helper (and before that past it for 64 paths), now travels on standard input. Proven on Windows Server through PowerShell 5.1 by `TestCLI_FactsGatherOnWindowsHoldsACLsLabelsJunctionsAndStreams`.
