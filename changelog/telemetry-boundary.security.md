Exported traces now carry identifiers only: each span keeps just the attribute keys on a fixed allowlist (which `PLEIADES_TELEMETRY_DENY_ATTRIBUTES` can narrow but never widen), masks and caps what it keeps, keeps only declared span and scope names, and drops error messages, stack traces and free status text, which stay in the log line carrying the same `trace_id`. An unknown HTTP method is recorded as `_OTHER` on spans and request metrics, inbound `tracestate` and `baggage` headers are no longer read, an inbound request's sampled flag no longer overrides `OTEL_TRACES_SAMPLER_ARG`, and the tracing SDK's own messages no longer print the values they fail to parse.
