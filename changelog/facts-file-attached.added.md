`facts.gather`'s files subset now records what a named path carries beside its content, which its `sha256` never covered: `file_attached.<path>` holds the kind (`xattrs` on macOS, FreeBSD and Linux, a resource fork among them on macOS), the names (at most 256, then `names_truncated`) and one digest over every name and value, always keyed. Its `state` says what could be read: `listed`, `unreadable`, or `unlisted` where the device has no tool to list them (Linux without `getfattr`), so a missing layer never reads as a clean one. Values are digested on the device and never cross the wire. `file_attached.` is a reserved fact family.
