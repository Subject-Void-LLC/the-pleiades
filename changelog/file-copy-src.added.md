`file.copy` takes `src`: a file in the project directory, sent to the device through the same checksum-compared, atomic write as `content`, so the command line can deploy a binary, an archive or a configuration file straight from a project. The path is relative to the project, stays inside it, passes through no symbolic link, never reaches `.pleiades`, and is a regular file of at most 64 MiB. A Walk-tier Runner cannot see the project, so there `src` is refused and `content` is the way.
