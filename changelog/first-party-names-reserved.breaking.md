Every first-party namespace is now reserved for The Pleiades whether or not a build includes that Collection: an external Collection can no longer use `kubernetes`, the namespace of a built-in fact family (`os`, `host`, `hardware`, `network`, `package`, `service`, `service_state`, `port`, `user`, `group`, `catalyst`), or a Collection's namespace in a build without it. An installed program using one of these is refused when Collections are loaded, and loading stops there, so the other programs in its directory do not load until it is renamed or removed. `pleiades validate` now names the first-party Collection that holds a method a build does not include, and the lists ship as `docs/reference/schemas/first-party.json`, growing only on a minor release.
