Added `controller setup`, which generates the master encryption key and the JWT secret, writes them where the deployment reads them (`.env` for docker compose, or a Secret and a values file for the Helm chart), and creates the first administrator. It refuses to replace a key while any stored data is encrypted under it, counting that data by kind, and says at the moment it creates the key what a later reinstall, upgrade or rotation needs from you. `make up` runs it the first time.
