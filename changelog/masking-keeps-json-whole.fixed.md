Masking a JSON document (a RESTCONF answer, `show ... | format restconf-json` through `net.ios.command` or `net.cli.command`, an `http.request` body) replaces each secret as the whole value it stands in, and the document still parses. A secret leaf's value used to be replaced wherever its text appeared in the document, so a GRE tunnel key of 100 (a leaf named `key`, masked in place as it still is) turned the tunnel's name and NHRP network-id into bare placeholders where JSON wants a number, and `10.255.100.1` into `10.255.<placeholder>.1`. A number is never added to a run's masking set, however long, and a masked copy that would no longer read as the JSON or XML it was is withheld with a reason rather than recorded.
