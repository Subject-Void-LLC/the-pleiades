A rollback now holds each recorded undo to the Collection declarations it was recorded under. An undo whose declaration's digest differs from this build's is refused, naming both versions and both digests, until `pleiades rollback --allow-skew <node>` (repeatable) or the API's `allow_skew` list accepts it by node; the plan's new `warnings` then name the digests it accepted, and a step so accepted carries `skew_accepted`. A Collection whose documentation alone changed needs no flag, a method moved to another group is a warning, and an entry recorded with no Collection identity is checked against this build alone and says so. Whatever is named, a recorded value of another type than the parameter now takes, and a parameter the undo now requires that the run did not record, are refused with `--leave` as the only answer. The CLI refuses `--allow-skew` naming a node with no skew or one the journal lacks; the Controller marks a named node accepted even where its own declarations match, since the Runner compares its own, and a Runner refuses a step recorded under other declarations than its own unless the plan accepted it. The flag is advisory until Collection identities are signed, since the digests are public. Every Collection group, version and digest a refusal or warning prints is quoted.
