`virt.vbox.media.prune` and `virt.vbox.vm.delete` decide what is inside a folder by its path's segments rather than its text: a disk or DVD image VirtualBox names through a `..` segment (with either separator), a UNC path, a stream, or a folder name differing only in a letter outside ASCII (the Kelvin sign in place of K) is no longer deleted as one inside the machine folder or the VM's own folder. Every host path the `virt.vbox.*` methods send now refuses a `..` segment between forward slashes too, where only backslashes were read before, so `G:\Lab/..` no longer names `G:\`.
