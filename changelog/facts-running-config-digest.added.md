`net.ios.facts` and `net.frr.facts` now record `config.running_digest`, a keyed digest of the running configuration and never its text, with the lines each platform changes on its own (build banners, byte counts, timestamps) removed first, so it changes only when the configuration does. It is keyed under the project's key on the CLI and the Controller's on the Walk tier, since a plain digest of a short secret can be guessed. `config.` is now a reserved fact family that an external Collection cannot declare.
