A `windows_server` device can pin the authority that issued its WinRM HTTPS listener's certificate with `tls_ca_pem`, and the name that certificate is checked against with `tls_server_name`, so a host with a private certificate is verified without adding that authority to the system's roots. Both apply to the HTTPS listener only: they are refused on port 5985, and a run refuses them over HTTP. The Windows lab setup script now writes the authority as `ca.pem` and prints the `add-host` and `add-credential` commands.
