`validate` now refuses `lock_acquisition: all_at_plan_time` on a task with `loop:`, `with_items:` or `until:`, so a runbook it passed may be refused. Such a task runs on each device on its own, and the run already refused it, but only when execution reached the task, after earlier tasks had changed devices; `validate` and `run` now stop before anything runs, with the reason the run gave. Remove `lock_acquisition` from the task, or give each item a task of its own.
