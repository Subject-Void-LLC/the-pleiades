Every stored fact now names the Collection its method came from (`by.collection` and `last_by.collection`: a built-in's first-party group, the version of The Pleiades that ran it and a digest of the group's method declarations, or an external program's file name and a digest of what it described), the same identity the run journal records for the task, on the command line and on the Controller. A value stored before it has none and its chain hash is unchanged, so a device's existing history still verifies. Both fact stores refuse to store an identity no build writes for its method, and the Controller stores a Runner's batch naming one with its facts and no identity, and warns. Reading returns each identity as it was stored: an edited one is found by the device's fact chain, and one that a later release's list of first-party groups would refuse still reads and verifies.
