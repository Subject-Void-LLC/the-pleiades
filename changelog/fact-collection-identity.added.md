Every stored fact now names the Collection its method came from (`by.collection` and `last_by.collection`: a built-in's first-party group, the version of The Pleiades that ran it and a digest of the group's method declarations, or an external program's file name and a digest of what it described), the same identity the run journal records for the task, on the command line and on the Controller. A value stored before it has none and its chain hash is unchanged, so a device's existing history still verifies. The command line's fact store refuses an observation naming an identity no build writes for its method and refuses such a history line on reading; the Controller stores a Runner's batch naming one with its facts and no identity, and warns.
