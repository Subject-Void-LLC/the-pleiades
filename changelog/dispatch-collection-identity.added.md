Each dispatch now names the Collections its runbook runs (`collections`: for each built-in first-party group, the Controller's version of The Pleiades and a digest of the group's method declarations as its catalog holds them), and a Runner compares each with its own build, warns in its own log and in the job's log (a `task.warning` event) where the declarations differ, and runs the job as before. The digests decide whether to warn and the versions only choose the wording: another build with other declarations, the same version with other declarations (a stale catalog or a corrupt build), a group the Runner lacks, and a method the Runner serves from an external program each have their own warning, and two builds with the same declarations warn nowhere. A Runner also drops any login seed key (`seed_*`) a dispatch carries, which no Controller sends, before a method can read it. A rollback dispatch's steps carry the Collection identity and undo digest their journal entries recorded, and a journal line whose identity holds a character only Go's Unicode tables call a format character still reads.
