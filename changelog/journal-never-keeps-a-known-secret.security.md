The run journal no longer keeps a recorded undo's value when it holds a secret the run knows, such as a named secret or a credential's value: the value is left out, the undo is marked withheld for a secret (`inverse_withheld`), and a later rollback refuses it by name before touching any device, unless `--leave` names it. Templated `rollback:` steps the journal keeps are held to the same rule.
