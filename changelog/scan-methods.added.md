New `scan.vuln`, `scan.sbom` and `scan.secrets` methods scan what a release ships, on the device that holds it, each running a scanner pinned by its image's index digest (OSV-Scanner 2.6.0, Syft 1.52.0, Gitleaks 8.30.0) in a fresh container on the device's own engine, with what it scans mounted read-only and no network unless it needs one. `scan.vuln` gates on severity and, with `fixable_only`, on whether a fix exists, online or against offline databases on the device. `scan.sbom` writes an SPDX 2.3 SBOM held to the NTIA minimum elements, with the operator's supplier on the subject alone, and a `SHA256SUMS` beside it, into a new directory a rollback removes. `scan.secrets` names each leaked credential by file, line and rule, never by its value. Both gates read one ignore file whose every entry needs a reason and an end date. `containerengine.RunOnce` gains read-only bind mounts, an environment, and standard error apart.
