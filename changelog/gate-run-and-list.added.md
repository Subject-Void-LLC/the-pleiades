New `gate.run` and `gate.list` methods run a project's own checks on a device from a YAML gate manifest: each check is a command run in a directory over SSH, or in a one-shot container from a digest-pinned image with no network and a read-only root, and yields PASS, FAIL or SKIP with the reason, its duration and the end of a failing check's output. Every check states a timeout, checks run one at a time unless raised, and a check skips on a precondition it declares rather than running to fail; a SKIP is never counted as a PASS.
