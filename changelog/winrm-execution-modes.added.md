Windows devices run a command three ways, named by `shell`: `none` runs a program with its arguments exactly as written, `cmd` runs one line through `cmd.exe`, and `powershell` runs a script, keeping a failing program's real exit code. The new `winrm_exec` task and `exec.winrm.shell` both accept `env`, which passes values to the command as `PLEIADES_` environment variables instead of as script text.
