`facts.gather` gathers three more subsets, each one fact per item and each read without root on Linux, FreeBSD, macOS and Windows: `files` (for the paths a task names in `files`, at most 64, metadata as `file.<path>` and, for a file anyone may read, its SHA-256, never the content (a private file's digest is kept only keyed and its size not at all, since a plain stored digest of a small secret can be guessed); a path the login cannot reach is `unreadable`, never `absent`), `ports` (each listening TCP socket and bound UDP socket as `port.<protocol>:<address>:<port>`, with the owning process where the login may see it) and `users` (each local account and group as `user.<name>` and `group.<name>`, never a password or its hash). `all` now gathers `ports` and `users`, and `files` whenever `files` names paths. A runbook that already gathers `all` now also records every listening socket and local account, which counts toward the 8,192 facts one task may record.
