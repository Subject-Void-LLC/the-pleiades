`make bsd-check` and `make win-check` run a branch's container-free packages on a FreeBSD and a Windows machine a Pleiades project manages, as `make mac-check` does on a Mac, and `make pr-check` runs all three beside the Linux passes. Windows runs them without the race detector (`testgate -race=false`). The container shards' recorded times now come from go test's own elapsed time.
