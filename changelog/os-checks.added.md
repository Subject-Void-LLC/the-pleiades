`make bsd-check` and `make win-check` run a branch's container-free packages on a FreeBSD and a Windows machine a Pleiades project manages, as `make mac-check` does on a Mac, and `make pr-check` runs them beside the Linux passes. Windows runs them without the race detector (`testgate -race=false`). A machine that is a VirtualBox VM (`PLEIADES_BSD_VM_HOST`, `PLEIADES_WIN_VM_HOST`) is started when a run needs it and its state saved when the run ends, interrupted or not, and `make pr-check` runs the two VMs one after the other, so a workstation holds one box's memory at a time. The container shards' recorded times now come from go test's own elapsed time.
