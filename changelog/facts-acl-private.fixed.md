`facts.gather`'s files subset now reads access control lists before keeping a plain digest. A file whose mode and directories let everyone read it, but whose list (or a directory's above it) denies anyone, or withholds read or search from a user or group it names, is private: its digest is keyed and its size not kept. macOS reads `ls -le` (any deny entry), FreeBSD and Linux read `getfacl` (an NFSv4 deny, or a POSIX.1e named entry or mask lacking the permission), and Linux without `getfacl` reads GNU `ls`'s `+` mark; a list that cannot be read is a restriction. A BusyBox system without `getfacl` shows no list, and there one is not seen.
