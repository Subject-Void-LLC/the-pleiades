`add-credential` now records the type and SHA256 fingerprint of a stored private key beside it, and `pleiades list-credentials` (text and `--json`) shows them without the master key, or "key fingerprint not recorded" for a key stored before this release. A run refuses a credential whose recorded fingerprint or type does not describe its key, before it connects, and the fingerprint is never written to a fact, a stat or the journal.
