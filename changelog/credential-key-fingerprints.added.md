`add-credential` now records each stored private key's type and SHA256 fingerprint, `pleiades list-credentials` (text and `--json`) shows them without the master key ("key fingerprint not recorded" for an older entry), and a run refuses a credential whose record does not describe its key, writing the fingerprint to no fact, stat or journal. `add-credential --generate` takes `--key-type` (`ed25519` by default, `rsa-3072`, `rsa-4096`, `ecdsa-p256`, `ecdsa-p384`), `--no-password`, `--json` and an enable secret, prints the key's type and fingerprint before its public key line, and refuses a mistyped type or a stored login before it reads any input or makes any key.
