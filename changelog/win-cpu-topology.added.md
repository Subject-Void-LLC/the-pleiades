`win.cpu.topology` reports a Windows host's logical processors as its scheduler sees them: each one's group, core, NUMA node, cache and efficiency class, which are a hybrid processor's performance cores, and the affinity mask that selects them. No WMI class carries efficiency classes, so it reads them from `GetSystemCpuSetInformation`, and a host whose PowerShell runs in Constrained Language Mode is refused with that reason.
