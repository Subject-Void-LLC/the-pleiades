`container.docker.run`, `stop` and `remove` now refuse a container name, image, port, volume or restart policy that docker would read as an option or that no engine allows, before anything reaches the device: an image of `--privileged` used to start a privileged container. Every value also travels in its flag's equals form, and `--` ends the options before the image and the name. A `docker inspect` that cannot reach its daemon is now reported as a failure rather than as an absent container, which had `run` create a container on an engine it never reached.
