The controller's facts key can be changed without losing stored facts: set the new key as `PLEIADES_FACTS_DIGEST_KEY` and the old one as `PLEIADES_FACTS_DIGEST_KEY_PREVIOUS`, and each device's stored history is re-keyed whole, with its order and times kept, while batches Runners sealed to the old key are still opened. The Helm chart and Compose pass the previous key; remove it once the controller logs that the rotation is complete.
