`virt.vbox.snapshot.delete` refuses a VM that is not stopped, in a check too: deleting a running VM's snapshot merges its disks while it runs, which on the lab host twice left the VM unreadable to VirtualBox. `virt.vbox.snapshot.take` of a running VM now records no undo and says so in a warning, so a rollback refuses that change by name before contacting anything, and `--leave` accepts it.
