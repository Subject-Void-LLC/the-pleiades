`virt.vbox.vm.screenshot` writes its picture into the project through the same writer every method's project file goes through: `dest` is now a path relative to the project directory, ending in `.png` (such as `shots/win-lab.png`), and one that is absolute, climbs out of the project, passes through a symbolic link or names `.pleiades` is refused, as is a run with no project, such as one on a Runner. It used to write to any path on the machine running the task, which on a Runner let a runbook replace any file the Runner's account can write. A runbook that named a relative `dest` from its project directory needs no change; one that named an absolute path names a path in the project instead.
