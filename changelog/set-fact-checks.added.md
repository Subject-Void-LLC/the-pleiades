`pleiades validate` warns when an `--extra-vars` value has a name a `set_fact` sets, since the extra variable wins and the fact is never read, and its refusal of a secret reference in a `set_fact` value now says why. The playbook converter no longer reports a precedence finding for a `set_fact` over a play's `vars`, where Ansible and the runbook read the same value, and still reports one beside a block's or a task's `vars`.
