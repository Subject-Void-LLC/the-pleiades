Added the `container.*` namespace for Docker and Podman, built on the engine's own API: run, create, start, stop, restart, remove, recreate, exec, info, list, logs, prune, copy_in and copy_out for containers, plus `container.image.*`, `container.registry.*`, `container.network.*`, `container.volume.*` and `container.engine.info`. Every method but `container.exec` supports check mode, and the parameters that reach the host (privileged, cap_add, devices, host volumes) are marked as host escapes in their reference pages.
