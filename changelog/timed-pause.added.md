Added `pause` (also `pleiades.builtin.pause`): a task holding the run for `seconds` or `minutes`, up to a day, once for the run rather than once per host, most often between `serial:` batches. A pause that waits for a person is refused. The dotted spellings `pleiades.builtin.fail`, `pleiades.builtin.assert` and `pleiades.builtin.set_fact` now pass `validate`, which used to refuse them although the engine ran them.
