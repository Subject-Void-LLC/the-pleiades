Added `http.wait`, which waits from the machine pleiades runs on until a URL answers with the status, and optionally the body, wanted: http.check's request repeated on the wait methods' own timeout, delay and sleep, a refused connection counting as not yet. It waits for a service published on this machine, such as Batfish's API, which `pleiades.builtin.wait.port` (looking from a device over SSH) cannot see.
