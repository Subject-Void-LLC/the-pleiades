`exec.command` and `exec.shell` with `chdir: "-"` now run in the directory named `-`. They used to run in the login's home directory, or in `$OLDPWD` when the device set one, and report success, because `cd` reads the operand `-` as "the previous directory" even after `--`. Their `creates` and `removes` guards, `file.remove`'s check of a directory named `-`, and an account home named `-` read by `identity.user` are fixed the same way.
