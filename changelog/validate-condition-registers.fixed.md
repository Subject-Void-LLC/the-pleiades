`pleiades validate` now refuses a `when`, `when_or` or `when_cel` that reads a register no task in the runbook registers, or only the task itself registers, the way it already refused such a read in a parameter template. A misspelled register used to pass validation and fail only when the run reached that task. A condition that tests for the register with `has()` or `in` is left alone, since it is written for the register's absence.
