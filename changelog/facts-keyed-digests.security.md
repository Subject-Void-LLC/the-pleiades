A file `facts.gather` describes that not everyone may read now keeps its digest as `hmac_sha256` (HMAC-SHA-256 under a key only the store holds, named by `hmac_key`) rather than none: the CLI keys it under a key derived from the project's master key, and a Runner seals it to the Controller, which keys it under `PLEIADES_FACTS_DIGEST_KEY` (base64 of 32 bytes; without it the Controller keeps no such digest and says so at start; Helm `secrets.factsDigestKey`, Compose `.env`). An unchanged file keeps its value, so drift still shows, and a reader cannot test guesses at a small secret against it. No raw digest reaches a report, a register, the broker or a store. A Runner also no longer counts the login's username as a secret, which had kept every fact naming the login (its own account, a file it owns) from being stored on the Walk tier.
