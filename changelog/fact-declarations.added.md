Every method now declares each fact it emits as stable (every value kept) or volatile (latest only, such as an uptime), and each stored fact says which run, task and Runner observed it, ordered by run rather than by clock. Stored facts form a per-device hash chain, checked with `pleiades facts <host> --verify` or `GET /inventory/devices/{name}/fact-chain` (tamper-evident, not tamper-proof).
