`become` is refused wherever sudo cannot reach: at validation for a device's CLI session (`net.ios.*`, `net.cli.*`), PostgreSQL forwards (`db.pg.*`), NETCONF and built-in actions, and when the task runs for WinRM (`svc.*` on Windows), a `gate.run` TCP precondition (which reported a skip before) and a container engine's forwarded socket. A task's result and journal name the account only when a connection really ran as it, so a task can no longer run as the login while its record says root; one that reached its device no SSH way runs as the login and warns. A change kept through a failure is undone as the account it ran as.
