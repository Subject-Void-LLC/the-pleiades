A task's `when`, `when_or` and `when_cel` can read the stored facts of the device it runs on with `pleiades run`, by a key written in the runbook (`facts["os.family"] == "debian"`), with what the run's own earlier tasks gathered on top. A key reads absent only when an earlier task of the run asked the device for it by name; any other key nothing holds, a family's item such as `package.nginx` included, fails the task rather than reading as false. A fact never reaches a parameter or any output, and on the Walk tier a runbook reading one is refused at launch, at a schedule's write and before any device is contacted.
