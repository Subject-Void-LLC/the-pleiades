Added `virt.vbox.media.prune`: it deletes the disks no registered VM uses and the leftover folders of VMs VirtualBox no longer knows, under the host's machine folder, keeping any disk a VM still depends on and any folder holding a registered VM's files. A folder left empty (as a VM delete leaves one) goes too, on the run after the one that emptied it. A check lists exactly what a run would remove.
