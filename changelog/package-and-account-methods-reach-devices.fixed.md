The package, firewall and account methods (`pkg.*`, `pkg.apt.*`, `pkg.dnf.*`, `fw.firewalld.*`, `identity.user.*` and `identity.group.*`) now run on a real `linux_server`; before, every one was refused before it ran, because no device type could satisfy the capabilities they require. Classify the server with `--classify linux_server,debian_family` (or `rhel_family`) for the package and account methods, and set the `firewalld` property to `true` for the firewall ones. A host added with `--classify` also keeps its classification's capabilities when the inventory is read back, which it used to lose.
