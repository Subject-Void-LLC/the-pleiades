Every read-only built-in method now says what it answers about a thing that is not there: `pleiades doc` prints an `absence` line and each reference page an Absence row, either that a thing not there is `exists: false` or why the method answers no `exists` (it lists, describes the device itself, is a gate, a wait or a probe), and the module catalog carries that reason as `noExistsReason`. An external Collection may set it too; `exists` beside a reason, or a reason on a method that changes things, is refused when the method is registered.
