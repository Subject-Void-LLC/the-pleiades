A credential whose `external` reference, or whose input source bound to an external-kind credential, names an input its type does not mark secret is refused: a write that keeps such a reference answers 400, one that binds such a source answers 409, and a job using a credential that already holds one fails at dispatch naming the credential and the input, where the resolved value used to be injected in plain text. Remove the reference or declare the input secret; the credential stays readable and editable meanwhile. The `file` secret source still reads one directory for the whole Controller, so a reference in any organization can name any file in it; the production guide now states that as a tenancy limit.
