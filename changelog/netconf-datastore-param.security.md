`net.netconf.config` takes the datastore to configure as `datastore`, not `target`. `target` is the key every task uses to name the device or tag it runs on, so `target: candidate` asked for the candidate datastore and also sent the task to any device or tag named `candidate`. A runbook that still passes `target` to this method now gets only the engine's meaning (the device or tag of that name, with the running datastore), so rename it to `datastore`; `pleiades migrate-playbook` maps `netconf_config`'s `target` to `datastore`.
