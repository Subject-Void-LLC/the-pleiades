A credential write naming another organization's record (a credential of another organization's custom credential type, a template binding another organization's credential, or a credential reading an input through another organization's source credential) is still refused with a 403, and the refusal now names that record by the id the request sent. It used to quote the other organization's credential type or credential by name, which a token holding `credential:write` without `credential:read` had no scope to read.
