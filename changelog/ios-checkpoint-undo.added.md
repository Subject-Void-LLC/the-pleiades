`net.ios.config` now keeps a checkpoint of the running configuration on the device before its lines (its default writable disk or flash) and asks the device what they changed: no difference reports unchanged, so a second run of the same lines changes nothing, and a change records an exact undo, the new `net.ios.replace`, which returns the device to the checkpoint through IOS's own `configure replace`, refusing when the device has been changed since unless `force` is set, and deleting the checkpoint files afterwards. `pleiades rollback` and a block's `rollback_on_failure` both use it. A device with nowhere to keep a checkpoint, or `checkpoint: false`, records no undo and reports the lines that would undo the change, masked, for the task's `rollback:` list. The IOS session now sets `terminal width 512`, so a long command's echo no longer garbles its output, and `net.ios.command` reports `dir` and `more` as unchanged reads.
