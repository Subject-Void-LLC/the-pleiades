`facts.gather` now records the SSH host key a device proved itself with, as `ssh.host_key.<type>` (`ed25519`, `ecdsa_p256`, `ecdsa_p384`, `ecdsa_p521`, `rsa` or `dsa`), valued as `ssh-keygen -lf` prints it (`SHA256:<base64>`), and only from a session whose known_hosts check accepted that key: never a bastion's key, nothing from a task that sets `insecure_skip_host_key_verify` (it warns that it did not record one), and nothing when more than one key of one type answered in one read, since then more than one server answers at the device's address. The facts are part of the `min` subset, a borrowed pooled connection still records the key its own login verified, and nothing reads them as trust: known_hosts alone decides what a session trusts. `ssh.` is now a reserved fact family, and `ssh` a reserved namespace, that an external Collection cannot use.
