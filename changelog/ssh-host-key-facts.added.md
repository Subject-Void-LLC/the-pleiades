`facts.gather` now records the SSH host key a device proved itself with, as `ssh.host_key.<type>` (`ed25519`, `ecdsa_p256`, `ecdsa_p384`, `ecdsa_p521`, `rsa` or `dsa`), valued as `ssh-keygen -lf` prints it (`SHA256:<base64>`), and only from a session whose known_hosts check accepted that key: never a bastion's key, nothing from a task that sets `insecure_skip_host_key_verify` (it warns that it did not record one), and nothing from a read that met more than one server at the device's address (a retried login that reached another server, or two keys of one type). The facts are part of the `min` subset, a borrowed pooled connection still records the key its own login verified, and nothing reads them as trust: known_hosts alone decides what a session trusts. `ssh.` is now a reserved fact family, and `ssh` a reserved namespace, that an external Collection cannot use. A baseline taken before this release with no `--keys` reads each new `ssh.host_key.*` fact as added, so drift reports it once on every SSH device: take the baseline again after the first gather, or narrow it with `--keys`.
