New `file.json` and `file.yaml` set, or remove, the value at a key path in a document on a device and keep the rest of it: JSON's key order and its numbers and strings exactly as written, at the file's own indent, and YAML's comments and order. Each refuses a document holding a duplicate key, and YAML a path through an alias; a key already holding the value is no change, and a write keeps the file's owner, group and mode. New `http.check` requests a URL and fails on an unexpected status or body, follows at most `max_redirects` and never a downgrade from https to http, and never returns or logs the body, only its size and SHA-256. New `win.schtask` registers, updates, removes or reports a Windows scheduled task over WinRM, from a constant PowerShell script that reads every value as JSON on standard input, so no value can become script.
