Added network change verification. `net.batfish.check` holds candidate configurations (FRR and Cisco IOS, secrets masked) to Batfish's model before anything is applied, with assertions on sessions, routes, flows, live routes and any Batfish question, scenarios with links or nodes down, and a refusal for every line or feature the model does not use unless it is accepted with a reason. `net.frr.config`, `net.frr.interface`, `net.frr.facts`, `net.frr.command`, `wait.routes`, `net.trace`, `net.ovs.bridge` and `net.ovs.port` apply and verify the change on FRRouting routers and Open vSwitch switches, each undoing to the state it found.
