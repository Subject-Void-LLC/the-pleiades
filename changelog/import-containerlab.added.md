Added `pleiades import-containerlab`, which makes a containerlab lab's nodes `generic_ssh` devices from the `topology-data.json` containerlab writes, refusing any node that is not the named lab's, and optionally stores their login, trusts their host keys and onboards them. The `batfish` device type reaches a Batfish service, over plain HTTP only at a loopback address unless its record allows a private network by name.
