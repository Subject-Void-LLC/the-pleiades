`http.request` calls a device's own API when its `url` is a path, such as `/interfaces`: the path is joined to the base URL of an onboarded `generic_http` device and the request carries that device's stored credential, sent as its `http_auth` property says. Only such a request carries a credential. It cannot leave the device's origin: a scheme, a host, a second leading slash and a `..` segment are refused, a redirect to another origin is not followed, and the task may set neither `Authorization` nor `Host`. A full URL behaves as before and carries nothing.
