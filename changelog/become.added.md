Added `become`, `become_user` and `become_method: sudo` on a runbook, a block or a task: the commands a method sends over SSH run as another account through `sudo -n`, with the narrowest key winning, `validate` refusing it where it cannot apply, the account recorded in the journal and a rollback replaying the undo as the same account. There is no sudo password; a login that sudo would ask one of is refused with sudo's own words.
