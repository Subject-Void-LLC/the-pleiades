The Controller ships a `pleiades_snmp` credential type of its own `snmp` kind, so a template can bind it beside a network login: on the native path it becomes the SNMP credential of each job device that can be logged into, keeping that device's login, and a Runner whose job carries a community shorter than 8 characters warns in the job log, before any task runs, that it is masked by shape only. A playbook job is given nothing from it.
