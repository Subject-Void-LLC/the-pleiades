`container.docker.run` now starts a container that exists under its name but is stopped (exited, or created and never started), as community.docker's `docker_container` does by default, and records a `container.docker.stop` pinned to its id as the undo; set `start: false` for a one-shot container whose command is meant to run once. A paused, dead or removing container is refused, naming what to do. `container.docker.stop` gains an `id` guard, stops by the id it inspected, and is now reversible: its undo is a `container.docker.run` that starts the container again from the image it was created from.
