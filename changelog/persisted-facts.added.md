A real run now keeps what its tasks observed about each device (what `facts.gather`, `net.ios.facts` and other methods emit) as that device's facts, one stored value per change with when it was last confirmed. The command line keeps them under `.pleiades/facts` and shows them with `pleiades facts <host> [<name>]`; the Controller stores what Runners report and serves them at `GET /inventory/devices/{name}/facts` and `/facts/{key}`.
