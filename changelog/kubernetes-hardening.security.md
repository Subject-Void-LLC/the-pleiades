A cluster is reached only with the credential stored or bound for it: a Runner's own ServiceAccount, `KUBECONFIG` and `~/.kube/config` are never read, and a template's SSH login never reaches a cluster. What an API server answers is untrusted: discovery reads at most 128 MiB in all and keeps a bounded number of rules, and an error quotes at most 512 bytes of the server's text with control characters escaped.
