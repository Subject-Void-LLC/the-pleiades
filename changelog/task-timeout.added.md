A task takes Ansible's `timeout:` key: the whole seconds it may run on each device before it is stopped and fails, saying its timeout ran out, and `pleiades adhoc --timeout` sets it for one call. A launch's own timeout still bounds every task, and the smaller wins. A timed-out SSH command is sent `SIGTERM` before its session closes, so the work stops on the device too. `pleiades forge migrate-playbook` now converts a task's literal `timeout:` instead of blocking it.
