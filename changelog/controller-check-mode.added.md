Added check mode to the Controller: `POST /api/v1/templates/{id}/check`, or a runbook template's launch form set to check, runs the job as a check on every device, changing nothing, and the job and the Jobs page show its mode. A check asked for at any level cannot be turned back into a real run, and a Runner older than this release never receives a check, so one waits for an upgraded Runner instead of running for real. A finished check job reports `check_complete` and how many tasks went unchecked, so a check that could not answer for everything is never read as a clean one.
