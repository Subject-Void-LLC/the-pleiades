A project's source URL may no longer carry a token as its user name over HTTP (`https://<token>@github.com/org/repo.git`), which a forge accepts and which was stored in plain text and returned by the API, because only a password was refused before; nor a password in an scp-like ssh URL (`git:password@host:path`). A project stored that way keeps syncing, with a warning in every sync's log, and the API and the web UI now show its URL with the credential replaced by `redacted`. Give the credential to the project instead.
