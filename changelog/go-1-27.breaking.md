The Pleiades is built with Go 1.27.3 and its module requires Go 1.27, so an external Collection built on `pkg/external` needs Go 1.27 or later (`pleiades forge new-external` now writes `go 1.27.0`), and the macOS binaries need macOS 13 Ventura or later. On Windows and macOS the system certificate pool now honours `SSL_CERT_FILE` and `SSL_CERT_DIR` when they are set, using Go's own verifier over those roots instead of the platform's; a device whose TLS pins its own CA (`tls_ca_pem`) is unaffected.
