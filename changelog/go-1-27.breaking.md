The Pleiades is built with Go 1.27.3 and its module requires Go 1.27, so an external Collection built on `pkg/external` needs Go 1.27 or later (`pleiades forge new-external` now writes `go 1.27.0`), and the macOS binaries need macOS 13 Ventura or later. On Windows and macOS, when `SSL_CERT_FILE` or `SSL_CERT_DIR` is set, every connection verified against the system roots (a Vault source, telemetry export, webhooks) now trusts only the roots they name, through Go's own verifier instead of the platform's, where before these variables were ignored, so a file naming one corporate CA leaves the public roots untrusted on those connections; a device whose TLS pins its own CA (`tls_ca_pem`) is unaffected.
