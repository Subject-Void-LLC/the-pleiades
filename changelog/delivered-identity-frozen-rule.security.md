The Controller now holds the Collection identity a Runner's facts batch or journal rows carry to a fixed rule that
reads no Unicode table: its shape, and a group holding no bidirectional control, zero width character, joiner, line
or paragraph separator, soft hyphen, Hangul filler, variation selector, tag character, other invisible format
character or private-use character. So whether an identity is kept no longer depends on the toolchain the Controller
was built with, and one its own tables would refuse (a character they have not assigned) is kept and logged at info
level. A refusal of an identity or an undo digest is fixed text that repeats none of it. The Controller's facts and
journal consumers, the run journal reader and a rollback plan name a delivered or recorded group, version, digest,
program name, method or node cut to 128 bytes with every byte outside printable ASCII escaped, and say nothing about a
facts batch until it is stored, so a batch redelivered after a failed write is not noted twice.
