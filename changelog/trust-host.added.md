`pleiades trust-host <device>` adds a device's SSH host keys to the known_hosts file every SSH connection verifies against (`PLEIADES_KNOWN_HOSTS`, or `~/.ssh/known_hosts`). `--from-console <virtualbox host>` reads the keys a VM printed on its serial console, over the host's authenticated WinRM connection, so they are the VM's own. `--first-connect` takes whatever answers at the device's address, and warns every time. Keys that differ from ones already trusted for the address are refused unless `--replace` is given.
