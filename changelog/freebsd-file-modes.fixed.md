The file methods read a file's mode on BSD with its setuid, setgid and sticky bits; they were read without them, so on FreeBSD a setgid directory looked like 0755, `file.permissions` never cleared the bit, and a directory asked to keep setgid reported a change on every run. Onboarding a FreeBSD host as `generic_ssh` now grants the file methods, proven against a real FreeBSD 15.1 host.
