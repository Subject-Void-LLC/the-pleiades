Added `async:` and `poll:` for every method, as in Ansible. `async: N` is a hard limit of N seconds on each device, after which the task fails, and a `rescue:` can answer it. `poll: M` reports the task still running every M seconds. `poll: 0` runs it in the background while later tasks run, its register holding `ansible_job_id`, and the new `async_status` action waits for the job and returns its result. On SSH devices an async task's commands run detached on the device: they survive a dropped connection (the polls reconnect), and the limit stops the whole process group. A run never ends with a job nobody collected, and the job's change is journaled for `pleiades rollback`.
