`controller setup --jwks-url <url>` sets a deployment up to check API tokens against an identity provider, writing `JWKS_URL` and no `JWT_SECRET` (with `--force`, moving an existing deployment off its secret), and `setup --check` and `make up` accept such a file. The Helm chart takes `controller.jwksUrl`, which sets `JWKS_URL` and reads no `JWT_SECRET`, and `setup --target helm --jwks-url` writes it.
