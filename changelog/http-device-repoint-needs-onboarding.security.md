A `generic_http` device's discovery now holds only for the base URL, credential mode and TLS settings it was made against, so changing any of them, by `set-host`, the Controller, a sync or a hand edit of `inventory.yaml`, stops the device's stored credential being sent anywhere until `pleiades onboard` runs again. Before, anyone who could edit inventory could repoint an onboarded API device and have its credential sent to the new host on the next call. A `generic_http` or `generic_grpc` device onboarded before this release must be onboarded once more.
