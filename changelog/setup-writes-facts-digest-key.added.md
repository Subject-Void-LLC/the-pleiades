`controller setup` now writes `PLEIADES_FACTS_DIGEST_KEY`: into `.env` for Compose, and into the Secret it writes for Helm, whose values file sets `secrets.existingSecretHasFactsDigestKey: true`. Running setup again over a `.env` written before it did adds only this key and leaves every other value as it was. Setup never replaces one, since a new key reads as every private file's digest changing at once.
