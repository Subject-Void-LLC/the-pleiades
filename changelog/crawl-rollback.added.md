Added `pleiades rollback <run-id>`, which undoes a run's changes newest first from its journal and refuses as a whole, before contacting any device, when a change cannot be undone exactly, naming the flag that accepts each problem (`--leave`, `--allow-partial`, `--allow-unknown`, `--despite-run`). Added `pleiades journal list` and `pleiades journal show <run-id>` to read a project's runs, both with `--json`.
