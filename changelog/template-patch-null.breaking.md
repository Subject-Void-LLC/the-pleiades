`PATCH /templates/{id}` refuses a null on any of the template's own fields, or on `survey.enabled` or `survey.questions`, with a 400 that names it, where a null used to clear the field; leave a field out to keep it, or send an empty value to clear it. It also refuses a `kind`, `definition` or `inventory` that differs from the stored one with a 400 naming the field, where it used to accept and ignore it and answer 200; sending the stored value is still accepted.
