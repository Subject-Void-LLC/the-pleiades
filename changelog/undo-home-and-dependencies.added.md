Undoing `identity.user.create` now also removes the home directory it made, but only while that home still holds exactly what `useradd` copied into it and is still where it was made; a home used or moved since is kept, with a warning. Undoing `pkg.apt.install` now also removes the packages the install pulled in, while nothing else needs them; an install that pulled in more than 128 is undone by removing the package alone, and `apt-get autoremove` takes the rest.
