A task reaches a device's container engine through this machine's own socket (`engine_local`) only from the `pleiades` command line. A Runner, and its per-task child, refuse it at task time, naming `pleiades run` or onboarding over SSH or TLS: a Runner's machine is never the device, and two Runners built from one image can share Podman's identity, so the identity pin alone could not tell them apart. Onboarding already granted the capability only from the command line.
