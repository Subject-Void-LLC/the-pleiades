`file.directory` now gives every parent directory it creates the mode, owner and group the task names, as `ansible.builtin.file` with `state=directory` does. It used to give them only to the directory the task named, so `path: /srv/secret/app` with `mode: "0700"` left a newly created `/srv/secret` at the umask's mode, usually world-readable. A parent that already existed is never changed.
