Added the `kubernetes_bearer_token` credential type, AWX's own, and `pleiades_kubernetes_client_certificate` for clusters that authenticate x509. On the native path a bound one authenticates only the cluster whose API server it names; on the Ansible path it sets AWX's `K8S_AUTH_*` environment, except that verification is turned off only by `verify_ssl: false`, never by a missing authority. An EKS cluster (`eks_cluster_name`, `aws_region`) authenticates with tokens minted from its AWS key, with no `aws` program run.
