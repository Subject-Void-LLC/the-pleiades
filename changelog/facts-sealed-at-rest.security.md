Stored facts are sealed at rest on both tiers. The controller finds a fact's row by a keyed token of its name, seals the name and value together under the master key and bound to that row, and keys the hash that detects a change; the command line seals each line of `.pleiades/facts` under a key derived from the project's master key. A Runner seals each batch of facts to the controller's public key before publishing it, so the message stream holds none in plaintext.
