A value a `secret_mask:` marks secret is now kept out of every stored fact by its value, so it is no longer stored under another key that holds the same text. A run whose runbook has any `secret_mask` stores its facts only at the end, and only if every masking task ran and succeeded; otherwise it stores none. This changes `--tags` runs: a run whose tags leave out a masking task now stores no facts at all, where it used to store the facts not named by the mask.
