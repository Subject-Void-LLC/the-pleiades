# Filter reference

Every function and macro callable from a `when`, `when_or` or `when_cel` expression, beyond CEL's own built-in operators (`==`, `&&`, `in`, and so on; see the [CEL language definition](https://github.com/google/cel-spec/blob/master/doc/langdef.md) for those). A filter is not a Collection method: it is a pure, deterministic function of its arguments, with no device, no capability and no execution context. This page is generated by diffing the real CEL environment `engine.NewCELEvaluator` builds against a bare baseline with no libraries added, so a function or signature listed here is proven callable, not merely intended.

A signature written `filters.safeInt(dyn, int) -> int` means the first argument accepts any CEL type (converted to a string before parsing); a signature's own fallback argument, where one exists, keeps its exact declared type, so a value the wrong literal type there fails to compile rather than being silently coerced.

## Network & addressing (`ext.Network`)

cel-go's own `ext.Network()`, built on Go's `net/netip`. `ip` and `net.CIDR` values are opaque types with a custom type adapter; a `net/netip.Addr` or `netip.Prefix` from Go code converts into this environment directly. Parsing is strict: an IPv4-mapped IPv6 address or a zone suffix is rejected, not silently accepted.

## Encoding (`ext.Encoders`)

## Optional values (`cel.OptionalTypes`)

cel-go's own `cel.OptionalTypes()`. This is the environment's answer to Ansible's `default` filter: `stat.?retries.orValue(0)` reads as "the value at `retries` if present, otherwise `0`", and covers a field that may be **absent** entirely. It is a different problem from a field that is **present but malformed**, which the `filters.safe*` family above answers instead; the two are not interchangeable.

### `_?._`

if the field is present create an optional of the field value, otherwise return optional.none()

- `dyn _?._ string -> optional_type(<V>)`
  - `msg.?field // optional.of(field) if non-empty, otherwise optional.none()`
  - `msg.?field.?nested_field // optional.of(nested_field) if both field and nested_field are non-empty.`

### `_[?_]`

if the index is present create an optional of the field value, otherwise return optional.none()

- `list(<V>) _[?_] int -> optional_type(<V>)`
  - `[1, 2, 3][?x] // element value if x is in the list size, else optional.none()`
- `optional_type(list(<V>)) _[?_] int -> optional_type(<V>)`
- `map(<K>, <V>) _[?_] <K> -> optional_type(<V>)`
  - `map_value[?key] // value at the key if present, else optional.none()`
  - `// map key-value if index is a valid map key, else optional.none()`
  - `{0: 2, 2: 4, 6: 8}[?index]`
- `optional_type(map(<K>, <V>)) _[?_] <K> -> optional_type(<V>)`

### `_[_]`

select a value from a list by index, or value from a map by key

- `optional_type(list(<V>))[int] -> optional_type(<V>)`
- `optional_type(map(<K>, <V>))[<K>] -> optional_type(<V>)`

### `first`

return the first value in a list if present, otherwise optional.none()

- `list(<V>).first() -> optional_type(<V>)`
  - `[].first() // optional.none()`
  - `[1, 2, 3].first() ? optional.of(1)`

### `hasValue`

determine whether the optional contains a value

- `optional_type(<V>).hasValue() -> bool`
  - `optional.of({1: 2}).hasValue() // true`

### `last`

return the last value in a list if present, otherwise optional.none()

- `list(<V>).last() -> optional_type(<V>)`
  - `[].last() // optional.none()`
  - `[1, 2, 3].last() ? optional.of(3)`

### `optional.none`

singleton value representing an optional without a value

- `optional.none() -> optional_type(<V>)`
  - `optional.none()`

### `optional.of`

create a new optional_type(T) with a value where any value is considered valid

- `optional.of(<V>) -> optional_type(<V>)`
  - `optional.of(1) // optional(1)`

### `optional.ofNonZeroValue`

create a new optional_type(T) with a value, if the value is not a zero or empty value

- `optional.ofNonZeroValue(<V>) -> optional_type(<V>)`
  - `optional.ofNonZeroValue(null) // optional.none()`
  - `optional.ofNonZeroValue("") // optional.none()`
  - `optional.ofNonZeroValue("hello") // optional.of('hello')`

### `optional.unwrap`

convert a list of optional values to a list containing only value which are not optional.none()

- `optional.unwrap(list(optional_type(<V>))) -> list(<V>)`
  - `optional.unwrap([optional.of(1), optional.none()]) // [1]`

### `or`

chain optional expressions together, picking the first valued optional expression

- `optional_type(<V>).or(optional_type(<V>)) -> optional_type(<V>)`
  - `optional.none().or(optional.of(1)) // optional.of(1)`
  - `// either a value from the first list, a value from the second, or optional.none()`
  - `[1, 2, 3][?x].or([3, 4, 5][?y])`

### `orValue`

chain optional expressions together picking the first valued optional or the default value

- `optional_type(<V>).orValue(<V>) -> <V>`
  - `// pick the value for the given key if the key exists, otherwise return 'you'`
  - `{'hello': 'world', 'goodbye': 'cruel world'}[?greeting].orValue('you')`

### `unwrapOpt`

convert a list of optional values to a list containing only value which are not optional.none()

- `list(optional_type(<V>)).unwrapOpt() -> list(<V>)`
  - `[optional.of(1), optional.none()].unwrapOpt() // [1]`

### `value`

obtain the value contained by the optional, error if optional.none()

- `optional_type(<V>).value() -> <V>`
  - `optional.of(1).value() // 1`
  - `optional.none().value() // error`

### `optFlatMap` (macro)

perform computation on the value if present and produce an optional value within the computation

- `// m = {'key': {}}`
- `m.?key.optFlatMap(k, k.?subkey) // optional.none()`
- `// m = {'key': {'subkey': 'value'}}`
- `m.?key.optFlatMap(k, k.?subkey) // optional.of('value')`

### `optMap` (macro)

perform computation on the value if present and return the result as an optional

- `// sub with the prefix 'dev.cel' or optional.none()`
- `request.auth.tokens.?sub.optMap(id, 'dev.cel.' + id)`
- `optional.none().optMap(i, i * 2) // optional.none()`

## First-party filters (`filters.*`)

`pkg/filters`, registered under the flat `filters.` prefix, a namespace independent of a Collection's `<namespace>.<method>` FQCN (the two never cross-reference each other, so no collision is possible even in principle). Every function here is independently unit-tested as plain Go, with no dependency on CEL; `internal/engine/cel_filters.go` is the only translation between the two.

### `filters.safeBool`

parse a value as a boolean, accepting 1/t/true/yes/on and 0/f/false/no/off case
insensitively (a superset of Go's own strconv.ParseBool, matching the truthy spellings
YAML 1.1 and Ansible both already use and that real device CLI output commonly prints).
Any other value, including an unrecognized word or an empty string, returns fallback:
there is no built-in default for an unrecognized spelling beyond what the caller passes.

- `filters.safeBool(dyn, bool) -> bool`
  - `filters.safeBool(stat.enabled, false) // stat.enabled == "yes" -> true`
  - `filters.safeBool(stat.enabled, false) // stat.enabled == "maybe" -> false (fallback)`

### `filters.safeFloat`

parse a value as a base-10 floating-point number, returning fallback if it is present but
malformed, or if it parses to NaN or an infinity (refused deliberately: a NaN silently
makes every downstream comparison false, the opposite of what a safe cast should do). See
filters.safeInt's own documentation for the missing-versus-malformed distinction; the same
applies here. The fallback argument must be a double literal (0.0, not 0): CEL does not
promote an int literal to double automatically.

- `filters.safeFloat(dyn, double) -> double`
  - `filters.safeFloat(stat.load, 0.0) > 3.5 // stat.load == "4.2" -> 4.2 > 3.5 -> true`
  - `filters.safeFloat(stat.load, 0.0) // stat.load == "NaN" -> 0.0 (fallback)`

### `filters.safeInt`

parse a value as a base-10 integer, returning fallback if it is present but malformed.
The value may be any type; it is converted to a string before parsing, so this is safe to
call on a dyn field whose runtime type is not known ahead of time (a device may report the
same field as an int on one firmware and a string on the next). For a value that may be
absent entirely, use the environment's own optional-chaining syntax instead:
stat.?retries.orValue(0). filters.safeInt does not solve that problem and should not be
reached for as if it did.

- `filters.safeInt(dyn, int) -> int`
  - `filters.safeInt(stat.retries, 0) > 3 // stat.retries == "7" -> 7 > 3 -> true`
  - `filters.safeInt(stat.retries, 0) // stat.retries == "abc" -> 0 (fallback)`
